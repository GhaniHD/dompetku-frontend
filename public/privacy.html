Privacy Policy

Last updated: November 1, 2026

This page describes how the MyFulus Backup Tool handles data. The tool is a private, single-owner utility that creates nightly backups for MyFulus, a personal finance application. It is not offered to the public and has no other users.

What the tool does

Every night, the tool packages the MyFulus database and uploaded files, encrypts the package on the server, and uploads the encrypted file to the owner’s own Google Drive. Older backups are deleted automatically after a fixed retention period.

Access to Google data

The tool asks for one Google permission: the drive.file scope. With this scope, the tool can only see and manage files and folders that it created itself. It cannot read, list, or change any other file in the Google Drive account.

Data we collect and store

  • The tool does not collect personal data from visitors or from any other person.
  • It stores only an authorization token for the owner’s Google account, kept in a configuration file on the owner’s private server.
  • The backup files contain MyFulus application data. They are encrypted before they leave the server, and only the owner holds the key to open them.

Sharing and selling

Data accessed through the Google API is never shared with third parties, sold, used for advertising, or used to train any model. It is used only to store and delete the encrypted backup files described above.

Google API Services User Data Policy

The tool’s use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Retention and revoking access

Backups are kept for a limited time and then deleted automatically. The owner can revoke the tool’s access at any time from the Google Account permissions page at myaccount.google.com/permissions. Revoking access stops all further uploads.

Changes to this policy

If this policy changes, the updated version will be posted on this page with a new date.
